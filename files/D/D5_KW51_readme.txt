- A detailed description of the data set is provided in: 
K. Maes and G. Lombaert. Monitoring railway bridge KW51 before, during, and after retrofitting. ASCE Journal of Bridge Engineering. Submitted for publication. 

- The data set is structured as follows:
 * "traindata_yyyymm" - train passage data for year "yyyy", month "mm".
 * "ambient_yyyymm"   - ambient vibration data for year "yyyy", month "mm".
 * "trackedmodes"     - identified modal characteristics.
 * "matlab_functions" - MATLAB functions that enable plotting the data.
