# Pre-purchase priority — Hanoi bridge SHM architecture

1. **ISO/IEC/IEEE 42010:2022 (H1)** — first purchase; governs the architecture-description deliverable and traceability from stakeholders/concerns to viewpoints, views, models and correspondences.
2. **ISO 55001:2024 (H2)** — first wave; defines the asset-management-system requirements the SHM platform must serve, especially decisions, data/knowledge, lifecycle, risk and performance.
3. **ISO/IEC 27002:2022 (H4)** — first wave; use for solution-level security-control design. Add **ISO/IEC 27001:2022 + Amd 1:2024** immediately if an ISMS boundary, conformity or certification is in scope.
4. **ISO 13824:2020 (H5)** — first/second wave; purchase before ISO 2394 for risk-informed monitoring, maintenance, treatment and emergency-decision architecture.
5. **ISO/IEC 25010:2023 (H3)** — second wave; translate architecture concerns into platform quality attributes and acceptance criteria. Add 25019:2023 only for formal quality-in-use requirements.
6. **ISO 2394:2015 (H5)** — second/third wave; quantitative reliability verification, target reliability and threshold calibration. Check revision status just before ordering.
7. **ISO 15686-5:2017 (G10)** — later; economic/LCC justification and alternatives analysis, not core architecture definition.
8. **ISO 55000:2024 (H2)** — useful companion for controlled vocabulary; buy with 55001 if budget allows.
9. **ISO 55002:2018 (H2)** — defer because revision is underway; use IAM Anatomy v4 and BSI's 2024 guidebook pending replacement, unless implementation work cannot wait.

## Edition traps

- Do not buy ISO/IEC/IEEE 42010:2011, ISO/IEC 25010:2011, ISO 15686-5:2008, ISO 13824:2009 or ISO 2394:1998 for current implementation.
- ISO/IEC 25010:2023 no longer carries the old combined quality-in-use model; that topic is now ISO/IEC 25019:2023.
- Treat ISO/IEC 27001:2022/Amd 1:2024 as part of a current 27001 procurement.
- Recheck ISO 2394 and ISO 13824 immediately before purchase because their official pages show review activity.
